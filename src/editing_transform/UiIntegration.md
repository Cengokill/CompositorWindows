# Native transform sessions

`ui/TransformActions.cpp` supplies hit testing, direct handle gestures, selected-pixel Ctrl-drag, menus and transform options. `ui/TransformSessionActions.cpp` supplies persistent Free Transform/Distort state, publication, Apply/Cancel and button state. Both compile against supported Qt6.8.3/VS2022 with `/W4 /WX /permissive- /Zc:__cplusplus`; the first isolated passing compile is `evidence/graphics/transform-ui-01`.

Root integration adds `TransformSessionState.h`, a `unique_ptr<editing_transform::TransformSessionState> transformSession_`, `EditorProject* transformOwner_`, `autoSelectLayers_` and `transformControls_` to MainWindow. Existing `transformDrag_` remains the current pointer gesture. Root calls `beginTransform` before selection handling, and `updateTransform` before selection updates whenever transformDrag exists. General cancellation calls `cancelTransformSession`, even between persistent gestures when pointerOwner is null.

Root refresh sends the pending draft through selectedTransform, sends the optional quad to NativeCanvas::setDistortionOverlay, and calls updateTransformActions. Persistent sessions show controls regardless of the ordinary Show Controls setting. Numeric inspector fields change the draft and republish; source disables those fields during distortion. Enter applies, Escape cancels. Ordinary tool, layer, Save and tab switches apply the pending persistent transform first. Apply/Cancel actions deliberately avoid the generic action wrapper that resolves ordinary pending work.

Free Transform uses the selected image pixels when there is a nonempty selection, otherwise the selected layer or visible bitmap descendants. A floating selection inserts one temporary layer immediately above its cleared source. It inherits opacity/blend/parent but no mask or clipping link, matching FloatingSelection.swift. The base retains its mask. Each preview starts from the same immutable original; Apply merges only the final draft, removes the temporary layer, restores the original active ID, and moves selection in one history transaction. Cancel and unchanged Apply restore exact original pointers.

Ctrl-drag inside a selection while Marquee/Lasso/Polygon/Wand is active moves its pixels; Ctrl+Alt duplicates the pixels. Ordinary Move continues to transform the layer. The selected-pixel move preserves an existing vector outline by applying the same whole-pixel offset. Affine and perspective selections currently publish resampled dense coverage; preservation of arbitrary vector curves through those mappings remains a gap. `PixelTransformSession::selectionPreview` obtains the selection without rendering a full-resolution merged image during the reduced floating preview. Its `affineOnly` flag matches the source live outline, which follows the affine draft until Apply even during perspective distortion; final selection coverage includes the homography.

Handle gestures use source Move/Resize/Rotate/Distort geometry and overlay hit priorities. Windows Ctrl maps source Command for layer picking and handle distortion; the snapping checkbox provides the separate source Control suppression. Shift and Alt preserve axis, angle, aspect reversal and center-pivot rules. Auto-select picks visible bitmap bounds, and disabled auto-select still permits moving the active layer from outside its bounds. Alt-drag duplicates a single image layer on the first actual movement, while Alt-click adds nothing. Alt duplication is currently gated off for an unlinked mask target. Group and multi-selection transforms move visible bitmap descendants only.

An unlinked selected mask transforms alone. A linked selected mask moves with the image. Other unlinked masks remain at their original document placement; linked separately placed masks follow their image. Distort previews are limited to a 2048-pixel longest side and Apply uses full source resolution with alpha trim. Group members take the group's perspective map. Flip H/V in the options bar toggles local image flips within the pending draft; the existing Flip Layer menu commits pending work and performs the source document-axis reflection.

`tests/editing_transform/TransformUiTests.cpp` drives actual menu/toolbar controls and NativeCanvas's public pointer callbacks. All six cases pass in `evidence/integration/ctest-release-04.log`. That executable predates the final affine-only live-outline call by seconds; the root must rerun the integrated harness after rebuilding. The separately compiled `pixel-transform-08-source-outline` run passes all twelve backend cases, including the new live-outline and selection cancellation assertions. The UI suite checks persistent multiple gestures, one undo, cancel, floating stack/merge without old-position ghosts, pixel move/duplicate, distortion, layer duplication, and linked/unlinked mask scope. Callback tests do not prove native mouse delivery, rendered handle appearance or human acceptance. The backend's Mac CoreGraphics/CoreImage differential gaps and large-transform performance limits remain unchanged. Root owns presented-frame validation and broader command routing.
