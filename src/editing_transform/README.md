# Native transform geometry

`TransformGeometry.h/.cpp` is C++20 over shared `core/Document.h` types. Link its source against `compositor_core`. The standalone test main is `tests/editing_transform/TransformGeometryTests.cpp`. Its runner uses supported VS2022 and `/W4 /WX`; evidence in `evidence/graphics/transform-01` has 18 passing cases, including 256 rotated handle/ratio/Shift/Alt/flip combinations. This is source-derived analytic evidence. Mac execution and native canvas interaction acceptance remain unverified.

## Canvas integration

1. Construct `ViewMapping{pointsPerPixel, documentTopLeftInView}` in logical DIPs. The rotation stem28 and hit radius10 are fixed DIPs. Build `OverlayGeometry::fromTransform` for the draft, or `fromCorners` for a distortion. Draw its outline, eight handles, and optional rotation handle.
2. Build `visiblePlacements(document, optionalDisplayedTransformCallback)` once for the press and pass it to `PressContext`, alongside the editable active transform, selected group box if applicable, active ID, auto-select, controls and pending-edit flags. `resolvePress` returns selected ID, handle/move mode, and duplication intent. Pressing outside the active layer still moves it. Transparent rasters remain selectable by transformed rectangular bounds, matching source.
3. Caller begins history/pending state. Retain `Drag{originalTransform, pointerDocumentPosition, mode, optionalOriginalCorners}` through the complete drag. Duplicate on the first actual drag event when requested; a click alone does not duplicate. The host must handle unavailable distortion rasterization before starting that intent.
4. Collect snap targets from canvas size and visible placements, excluding all moved members. `previewDrag` runs source math, whole-pixel/whole-degree rounding, then movement snapping with tolerance `10 / pointsPerPixel`. It returns guide positions. Distortion has no rounding or snapping. If `accepted` is false, retain the preceding preview.
5. Commit/cancel/history stay in the caller. For group members or linked placed masks use `following(originalPlacement, oldGroupBox, newGroupBox)`. Retain immutable originals throughout a drag. This preserves translations exactly and follows source affine decomposition for other changes, including deliberate shear removal.

`Modifiers` contains source semantic Shift/Option/Command/Control flags. The host must map physical Windows keys explicitly. Option means Alt behavior: center resize or duplication. Command picks/distorts. Source Control disables snapping. Mapping both command/control to physical Ctrl changes combined behavior and requires an explicit host decision.

## Distortion Apply

Add `Distortion.cpp` to the same target as `TransformGeometry.cpp`; link core. `Distortion.h` exposes the source homography, its inverse, mask corner transport, `warpRaster` and `warpGray`. `DistortionSession(originalLayer)` accepts a validated draft/quad through `update`, returns an immutable reduced `preview` (default longest side 2048), and full-resolution `apply` with alpha trimming. `cancel` returns the original layer exactly. Application preserves layer identity and metadata. The caller keeps distortion persistent until Apply and creates one history step.

Warp bounds use floor/ceil document coordinates, with side limits 30000 and area limit 100 million. A supplied cancellation callback is checked by output row and before publication; it throws `TransformCancelled` and leaves external state unchanged. Uniform 1×1 masks retain their original pointer. Linked local masks warp and crop with image alpha bounds; linked separately placed masks follow perspective over their own footprint; unlinked masks keep original document placement. Preview keeps the full shape bounds while Apply trims to visible alpha.

`tests/editing_transform/run-distortion.ps1` and `DistortionTests.cpp` exercise nine cases in `evidence/graphics/distortion-02-final`, including the upstream trapezoid and cutout assertions. The native warp uses the shared bilinear sampler at interior pixel centers and fixed 4×4 coverage on shape boundaries. This preserves integer identity images and thin edge slivers, but does not establish pixel equality with `CIPerspectiveTransform`. Sampling mode is retained on the resulting layer, as source does; filter interpolation itself still needs Mac comparison.

## Selected pixels

Add `PixelTransform.cpp` alongside `Distortion.cpp`/`TransformGeometry.cpp`; link core. Construct `PixelTransformSession(originalLayer, documentSelection, kind, duplicate)` and call `begin`. Image targets require a present, nonempty selection intersecting their pixels. Mask targets are refused by the caller, as source does. `kind=Move` lifts from the original source grid; `move(offset)` rounds the document offset and replaces earlier previews. `duplicate=true` keeps the source pixels; otherwise the original selection is cleared with destination-out before the lifted pixels draw source-over.

`kind=Affine` lifts a document-grid raster over the selection bounds, like the source floating selection. Use `draft()` for handles and `update(draft, optionalQuad)` for resize/rotate/flip/distortion. `preview`/`apply` return both the layer and moved selection. The merge grows the source pixel grid where required; a local mask grows white into new areas while retaining existing mask values. Separately placed masks keep their placement. Source layer identity, opacity, blend mode, parent and live clipping references remain intact. An unchanged transform restores original pointers exactly, including soft selection edges.

For source live Affine display, `floatingPreview()` returns a cleared base layer plus an independent floating layer. The base retains the original mask; the floating layer inherits opacity/blend/parent but has no mask or clipping link. Place it immediately above the base, using its stable temporary ID. Perspective uses a reduced preview up to 2048 pixels. The final `preview`/`apply` merge remains separate from this display and restores the original layer identity. The cleared base is cached and retains untouched tiles.

The caller publishes the returned layer and selection in one document/history operation. `cancel` returns both originals exactly; failed/cancelled rendering publishes nothing. `mapSelectionPoint` supplies the forward mapping for a host-owned vector outline, and `selectionBounds` retains untrimmed geometry outside the canvas. The shared core currently stores only dense document-grid gray coverage, so the returned selection raster clips off-canvas parts and resamples affine/perspective edges. This differs from the upstream persistent vector selection and remains a parity limitation. Physical key mapping, mask-target gating, active selection IDs and history stay in the host.

`tests/editing_transform/run-pixels.ps1` runs twelve cases. `evidence/graphics/pixel-transform-08-source-outline` passes `/W4 /WX`, including source move/duplicate, cancel, unchanged soft selection, 110×50 floating merge growth, mask growth, imported source growth, half-source-pixel movement, flip/perspective, floating mask/blend scope, selection-only preview/cancellation and tile sharing. `pixel-transform-02` retains two failures (extra column from normalize/denormalize roundoff and missing fractional boundary coverage); `pixel-transform-03` retains a warning-as-error while introducing the direct affine map. The fixes use an explicit pixel-to-document affine matrix and geometric rectangle coverage. CoreGraphics High interpolation and native UI acceptance remain unverified. Preview currently scans the complete resulting raster and dense selection grid; these sessions carry no 60 Hz performance claim.
