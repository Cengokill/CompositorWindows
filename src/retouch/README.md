# Retouch sessions

Compile `RetouchSession.cpp` and link `compositor_graphics` plus `compositor_core`. No Qt APIs are used. Shared graphics supplies all eight C modules, brush coverage, D3D11 and the canonical raster sampler. `tests/retouch/RetouchSessionTests.cpp` is a standalone main; `tests/retouch/run-native.ps1` builds the complete dependency set with supported VS2022 `/W4 /WX`.

The suite has 16 CPU and 16 WARP cases. These are native source assertions and analytic tests, not Mac differential evidence. No frame-latency or large-retouch performance claim has been established. Earlier `retouch-02`/`retouch-03-final` runs are superseded: they mistakenly inferred source-over healing at the call site without expanding `BrushRaster.draw`, which internally uses copy blending. That assumption and its false witness were corrected before final integration; see `retouch-05-live-preview` for the current passing run.

## Integration

Construct one `RetouchSession` with immutable original pixels, their layer/mask transform, document dimensions, fixed settings and the document-grid selection. For Clone, supply `Sources.cloneOffset`; `Sources.currentLayer` is optional and otherwise rendered from the original layer without its opacity/mask. For Sample All Layers supply a complete immutable document composite in `Sources.allLayers`, taken at stroke start. A missing source throws. This sample remains frozen through the entire stroke.

`CloneAlignment` retains the Option-click source and the first aligned offset. Call `setSource` to reset alignment. `strokeOffset` is a pure preview; `beginStroke` retains the offset. `aligned=false` recomputes it from the source for every stroke. `samplePoint` gives the source crosshair, including the active nonaligned stroke. Source offsets round to whole document pixels with halfway values away from zero.

Call `begin(documentPoint)`, `append(documentPoint)`, and `preview()` for immutable source-grid snapshots. `commit()` flushes the replaceable brush tail, finishes healing if needed, and is idempotent. `cancel()` returns the original shared raster. Stop using the session after commit/cancel. On an exception cancel the session; no external document/history state has been modified by this API. The caller owns one history transaction, selection/target changes, worker scheduling, source-state checks and publication. The unchanged tile identities are retained in every returned image. A source-grid extent does not expand here, so painting/cloning beyond imported raster bounds remains outside this slice.

The mask overload accepts immutable `GrayRaster` and supports Blur alone, matching source retouch restrictions. Use `previewMask`, `commitMask`, `cancelMask`; the original gray pointer survives cancellation, and materialized gray previews are cached by retained raster identity. Gray storage is currently dense, so obtaining a changed mask preview copies the complete gray grid. The image `preview()` of a mask target is opaque grayscale.

The host chooses a new `healingSeed` per real stroke; tests freeze it. All three healing modes call the copied `spot_heal` C algorithm using the original raster, a coverage region expanded by `(max(paintedWidth,paintedHeight)+32)*3.2`, source opacity and the mode's source index. C execution is synchronous and cannot be interrupted internally. Discard/cancel the pending result if the host cancels during worker execution.

## Source contracts and remaining comparisons

Source pinned at `a19db9011282399785dc18efcfded904627bdcc2`: `CloneStamp.swift`, `BlurTool.swift`, `SmudgeLiquify.swift`, `BrushStroke.swift:443,758`, `EditorSession+Brush.swift`, `CloneStampTests.swift`, `SpotHealingTests.swift`. Original MIT notice retained here. Exact source tests for the three-stroke clone example and all three gray-stripe blemish repairs pass.

Clone paints a source-over sample through the shared continuous brush coverage. Stroke overlap caps opacity, and selection multiplies once. Blur freezes a softened current-layer sample once, paints it source-over and therefore compounds only across separate strokes. Sigma follows source `clamp(diameter/10,1.5,30)`. The current CPU Gaussian is separable, truncated at three sigma and normalized. Image edges are transparent; mask document edges clamp. CoreImage Gaussian/High sampling exactness requires Mac comparison.

Healing preview is the source dark wash at alpha0.45, independent of healing opacity. The C call sees raw coverage without selection; the final draw applies selection once. `BrushRaster.draw` internally sets copy blending, so the healed region replaces the base through selection. Translucent pixels outside coverage preserve their original RGBA exactly; the native witness checks `(50,50,50,128)` remains unchanged.

Smudge and Liquify work on a document-sized active-layer snapshot. Neither paints on an initial click. Smudge spacing is `max(1,diameter*0.08)`, Liquify spacing `max(1,diameter*0.025)`; shorter events accumulate from the last accepted point. Smudge carries RGBA pixels and picks up new material according to strength. Liquify samples a per-dab scratch region behind brush movement using the source float bilinear formula. Both use source smoothstep falloff, hardness capped0.98, strength at least0.01. Results copy back through a hard tip four pixels wider than the tool, which allows alpha removal. These formulas have distinct one-dab witnesses in the native test.

`preview()` for warp uses source-grid projection and selection clipping, showing the eventual commit result. For the upstream live display use `warpDocumentPreview()`: it returns the immutable document working image before final selection clipping, cached by the accepted dab revision. Draw across the document with the original layer opacity/blend and its owned mask retained at its original document placement. A native witness checks that the live document preview changes outside selection while the commit preview keeps those pixels. No perspective distortion or retouch outside the original raster extent is implemented here.

`Metrics` reports explicit document rasterizations, working buffer pixels, Gaussian scratch size, healing region size, warp dabs and published tile copies. Retouch does not call `Raster::rgba`, but Blur/Warp/source preparation do explicitly materialize document-sized pixel buffers; zero `rgba` calls do not mean zero full-image work. Blur currently evaluates the separable kernel on CPU. Warp recomposes all touched coverage tiles per preview. These paths need separate performance work before a 60Hz claim.
