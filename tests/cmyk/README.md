# CMYK fixtures

`synthetic-cmyk.icc.base64` is generated by `python tests/cmyk/generate_profile.py` using only the Python standard library. It is an original MIT-licensed ICC v2 output profile with forward/reverse LUT16 tables, D50 XYZ PCS and an idealized subtractive model with 20% desaturation. The ICC bytes are stored in Base64 text and decoded by the C++ test helpers; no Python installation is needed to run the tests. File-picker tests prepare a temporary ICC outside the repository. It contains no vendor profile data and must not be used for printing. The generator and fixture belong to this repository's MIT license.

`Fixtures.h` generates tiny PSD/PSB files in memory: inverted ink channels, separate alpha and mask, raw or PackBits rows, and 8/16-bit layers or merged images. These are parser regressions, not evidence of Photoshop exchange. Real Photoshop files and real printer profiles still need Windows verification.

The existing `migration_tests` executable exposes `cmyk profile`, `cmyk psd`, `cmyk persistence` and `cmyk export`. CTest registers them as `migration.cmyk_*`. Existing `imports.ui` and `export.ui` exercise cancellation, exact prepared export bytes and profile menu history. `display_profile.cmyk_native` uses the existing native display test executable and needs an interactive Windows desktop; its captures are build outputs.
