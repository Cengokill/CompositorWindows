# Development signing fixture

`TEST-ONLY-private-key.xml` is a newly generated RSA3072 test credential deliberately distributed with this local test harness. It is not a secret and must never be used for production releases. SHA256: `1c80e279b1bdae7188fddb20648d260a1556633be685605bb1bea51eb95d7133`.

The public modulus in `src/update/TestTrust.h` is its counterpart. Runtime verification accepts this key only when `Options.allowTestKey` or the helper's `--allow-test-key` is explicitly enabled, and only for the `test` channel. No production key or external release feed is configured.

Signatures cover the exact decoded UTF-8 manifest bytes, using SHA256 and RSA PKCS#1 v1.5. The signed manifest binds the product, channel, strict three-component version, and every payload's path, size and SHA256. Test feeds are generated by `scripts/update-make-test-feed.ps1`; source control need only retain the key fixture, scripts, source and compact result evidence.
