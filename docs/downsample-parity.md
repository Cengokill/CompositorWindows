## Implementation

`graphics/Downsample.h/.cpp` provides an immutable identity cache with the source100,000,000-pixel budget for retained reduced copies, least-recently-used eviction that protects the requested source, and the source factor-to-level rule(max6). Direct explicit-level requests continue until the requested level or1×1, matching the source helper. Both source and reduced handles are retained, preventing pointer reuse from mixing identities. Native cache work is serialized by a mutex; source work outside its lock is an implementation difference, not an output contract.

Every reduction is exactly2× with dimensions rounded up. RGBA uses transparent exterior corresponding to the source's8-pixel padding/4-pixel output crop, followed by channel≤alpha clamping. Gray repeats an odd last row/column and clamps the filter to its edges. Twenty horizontally filtered rows are retained at a time, avoiding a source-sized floating-point intermediate. The cache budget counts logical reduced pixels like upstream; it is not a bound on total retained source memory or native tile padding.

The source requests `kvImageHighQualityResampling`. Apple documents that flag as selecting **Lanczos-5**, while default resampling uses Lanczos-3. The adapter implements separable normalized Lanczos-5 with a2× antialiasing footprint. Exact vImage coefficients, intermediate rounding, border implementation, and CoreGraphics final interpolation remain unmeasured differential details. [Apple flag documentation](https://developer.apple.com/documentation/accelerate/kvimagehighqualityresampling)

`downsampleLayer` is an isolated `LayerRenderer.reduced/coverage` adapter: Nearest bypasses reductions, source origins survive flips/rotation, and ceil halvings expand coverage to exact powers of two instead of stretching the copy back into the old bounds. Original mask exterior semantics are retained in temporary render metadata. The source's final shrinking interpolation is Low; the native canonical bilinear sampler remains the final sampling stage. The final fractional sample remains bilinear; the new production StackRenderer path resolves raw canonical or live pixels before this sample.

Five additional native cases passed: finite/invalid factor guards and explicit-level stopping, odd gray edges/transparent RGBA/premultiplication, identity/LRU eviction and protected over-budget current entry, aligned piece phase, and odd-size coverage with flips/rotation plus Nearest bypass. They are regression evidence in addition to the four upstream invocations, not extra upstream coverage.

## Production integration

`SamplingSource.h/.cpp` supplies immutable raw RGBA or gray readers with dimensions, identity and halving origin. `ReducedSourceCache` resolves the selected level and builds reduced 256×256 tiles only when read. It uses the same normalized Lanczos5 coefficients, separable row ring and per-level premultiplied clamping as the eager adapter. The shared cache retains at most 256 reduced RGBA tile allocations (64 MiB) and 32 source-level entries. Source owners and live external handles can retain their existing input images; those input allocations are outside the reduced-tile budget. Gray tiles currently use the same RGBA backing allocation bound while exposing only gray output. Reduction work is serialized, and recursive scratch rows are bounded by tile size and level rather than full image dimensions.

`Raster` and `GrayRaster` carry transient `samplingOriginX/Y`. Growth materialization uses old origin minus crop origin; level k starts at `alignment + floor(-alignment / 2^k) * 2^k` and ends at the matching ceiling of the far edge. PNG project encoding materializes pixels and loading resets this phase to zero, matching `ProjectStore.swift`81–93/165; no manifest fields were added. Existing fixed-grid Raster replacement preserves the origin through its value copy.

Growing brush snapshots expose raw source readers using the same final crop, dimensions and phase as their commit. Level zero retains the existing direct pixel kernels. Reduced canonical images, mask images, live snapshots and committed snapshots share the lazy filter. StackRenderer resolves image and mask levels from transform width divided by source width and output units. Nearest bypasses reductions. CompositeCache culling includes the aligned, ceil-extended coverage; changed reduced sources invalidate all output tiles until filter support can be mapped safely into the damage regions. Output viewport budgets remain 64 visible and 256 retained tiles.

Six additional native production cases pass in `downsample-03/reduced-source-results.log`: eager-vs-lazy byte equality for odd RGBA/gray extents and a 256-pixel boundary; inherited odd-crop phase; immutable identity/cache eviction and surviving handles; bounded reads of a 30000² virtual source with no RGBA materialization; actual StackRenderer reduction/reuse and Nearest bypass; and invalid level/alignment guards.
