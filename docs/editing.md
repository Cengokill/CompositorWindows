## Selection contracts

`SelectionOutline` owns immutable Direct2D geometry. Geometry combination occurs before rasterization, using winding fill. Adding an outline to itself preserves its antialiased silhouette. `fromCoverage` calls the unchanged upstream tracer: **every nonzero coverage value is included**; there is no 128 threshold. It preserves outer and hole winding and explicitly reports allocation or detail-limit failures. Converting a soft bitmap to an outline creates its binary silhouette, as the source tracer does.

Rasterization uses WIC PBGRA bitmaps and `D2D1_RENDER_TARGET_TYPE_SOFTWARE`, in at most 512×512 work tiles, extracting alpha as unmanaged gray coverage. Antialiasing is explicit. Integer rectangles are exact. Ellipse/path edge bytes and D2D curve flattening require Mac differential evidence. Native geometry uses Direct2D floats; coordinate and point-count guards prevent unsupported allocations. Raster dimensions are limited to 30,000 per side and 100 million pixels, while a transparent canvas can remain 30,000×30,000 without a selection bitmap.

`rasterSelection` stores both coverage and a shared immutable outline in the parent-owned `Selection` model. This preserves geometry through history. `moveSelectionCoverage` moves the outline when present; otherwise it translates the original coverage snapshot. Callers preview a gesture from its original snapshot. Moving an outline off canvas does not clip away its geometry. A later move back restores it. Outline and coverage must describe the same selection; callers replacing a bitmap must replace or clear its outline too.

Absent selection means unrestricted edits. A present, all-zero selection means edit nothing. Subtracting from absent selection leaves it absent. Subtraction that removes an existing outline produces a present empty selection. A degenerate completed draft deselects only in Replace mode. Intersect is an additional API operation; the pinned toolbar offers New/Add/Subtract. Expand/contract translates `Selection.swift`'s round-cap, round-join stroked band of width `2 * abs(delta)`, with the source 500-pixel limit; expansion clips to canvas, contraction can empty the outline.

`mappedCoverage` maps document selection coverage into the layer or placed-mask pixel grid. Its default linear interpolation and nearest-byte result are explicit native candidates for `PixelAdjust.coverage`. Nearest sampling is also available. Core Graphics transformed mask filtering and geometric canvas-edge coverage remain `blocked_reference`.

## Pixel editing and clipboard rendering

Edits return a complete `Layer` value. A changed source grid also changes the layer transform. Fill follows `BrushStroke`'s canvas extent, tile allocation bounds, and `BrushCommit`'s nonzero-alpha crop. Existing attached mask coverage is kept aligned; new image area receives white mask coverage. Explicit mask placements keep their placement. Clear requires a present selection, operates on existing image pixels, and uses the supplied background gray on masks. Invert keeps the existing pixel grid and computes exact premultiplied `[alpha-r, alpha-g, alpha-b, alpha]`; masks use `255-gray`. A selected uniform 1×1 mask expands onto the source grid before a partial edit.

Only changed immutable image tiles are copied when the grid stays unchanged. Unchanged operations return the original raster/layer value; no RGBA flattening occurs. A crop or source-grid shift can require new tiles. This immutable no-op policy also avoids committing source operations that allocate patches but produce identical pixel values. Full large-image speed is not inferred from tile identity checks: the upstream 12-megapixel invert timing assertion has not been executed.

`gradientLayer` previews from the **original** layer, so moving endpoints or changing settings does not accumulate prior previews. Lines shorter than 0.5 document pixels are no-ops. End colors extend beyond the line/rim. The default is foreground-to-transparent. Channel tolerances in the native gradient tests are exactly those already present in `GradientTests.swift` (3 levels normally; radial midpoint 5 and direction agreement 1). No Mac comparison was run and no acceptance tolerance was relaxed.

`copyPixels` renders only the requested region and returns its document origin. Current-image copy uses the raster and transform while disregarding layer opacity, blend, visibility and masks, matching `SelectionClipboard.swift`. Merged copy uses the caller's canonical renderer and applies selection coverage once after composition. Owned-mask copy is opaque gray before selection coverage. Placed-mask exterior classification uses the shared graphics thumbnail approximation for masks larger than 96 pixels; exact Core Graphics thumbnail agreement is pending. Source vector bounds use the pinned 0.001 rounding tolerance. Paste insertion, external PNG clipboard exchange/change counts, cut transaction handling, and selected-pixel transform/cancel workflows remain caller work.

## Shapes and document geometry

Shape JSON uses required `kind`, `red`, `green`, `blue`, and `cornerRadius` fields. `kind` is exactly `Rectangle` or `Ellipse`; numeric values must be finite, matching the persistence decoder. Rendering clamps color to the supported sRGB gamut and radius to half the shorter side; negative radius draws square corners. Finite out-of-palette values remain preserved in JSON, while their Mac rendering is unverified. Raster edits clear live shape metadata. Redraw at a new size keeps corner radius measured in document pixels and gives an attached mask explicit placement before changing the raster grid. Rounded-rectangle preview is capped at 2048 pixels on its longer side.

Canvas resize and crop retain original image handles and translate layer and placed-mask transforms. A colored extension is a separate bottom `Canvas Extension` layer; the old canvas intersection stays transparent, including existing artwork holes. Mixed shrink/expand is covered. Invalid allocations and transformed positions are rejected before returning a changed document. Changed size/crop drops selection. Canvas resizing preserves shape metadata, matching the low-level `CanvasResizer` record contract. The pinned `EditorSession.applyDocumentSize` reconstructs layers without shape metadata, so its UI path loses live shape state; this quirk must remain an explicit integration decision.

Image resize preflights every planned image/mask allocation, then independently rasterizes each transformed layer into its scaled upright bounds. This handles anisotropic scaling of rotated layers without pretending a sheared image is a simple rotated rectangle. It preserves IDs, stack metadata and hidden content, bakes rotation/flips into pixels, and clears shape metadata after a dimension change. Resolution-only edits retain source handles and transforms. Uniform and separately placed masks retain source pixels; attached nonuniform masks are resampled. Placed-mask transforms use the source's shear-dropping `placing` decomposition. The shared native sampler currently treats Smooth and High as bilinear; Core Graphics High-quality filtering and geometric edge antialiasing remain unverified.

Canvas flips transform every layer, placed mask, and selection. Layer/group flips preserve raster handles and honor linked/unlinked mask placement. Group members follow the pinned visible-raster membership rule. Crop geometry includes whole-pixel standardization, reverse drags, ratios, symmetric creation/resizing, all eight handles, and edge snapping. Viewport mapping, overlay-only repaint behavior, and gesture history remain UI tests.

## Preserved failures and remaining evidence

`audit/selection-key-source-test-conflicts.json` records two static **fail** conflicts: the pinned `pressMarqueeKey()` and `pressLassoKey()` only select the remembered tool kind; the corresponding tests expect repeated M/L presses to toggle its kind. The implementation does not invent a toggle or mark those methods passed. This is source inspection evidence, not a claimed Windows/Mac UI execution. Mac reference and an accepted behavior decision are required.

The previously recorded `SOURCE-TEST-CONFLICT-LEVELS-ALPHA` remains fail in the effects evidence. All missing Mac render, soft-mask, interpolation, shape-style interchange and thumbnail comparisons remain `blocked_reference`. The 37 native checks do not resolve those gates or the remaining selected-pixel move/duplicate/transform/cancel, clipboard, command eligibility, and complete UI/history assertion coverage.
