# Sparse growing brush

`graphics::GrowingBrushSession` paints in signed coordinates of the original layer pixel grid. The original raster stays immutable. Only affected 256-pixel coverage and output tiles are allocated; the virtual source extent can include an otherwise blank 30000×30000 canvas. Source grid phase follows the integral inverse-transformed canvas extent. Accumulated coverage, provisional tails, interpolation and GPU fallback reuse the existing BrushSession/BrushCoverage algorithms.

`begin`/`append` publish immutable `GrowingBrushSnapshot` objects. `pixel(x,y)` and `sample(x,y,w,h)` use the original source grid, including negative coordinates. `sourceBounds()` is the exact union of existing source bounds and nonzero painted alpha, and `transform()` maps that crop without moving existing content. Erasing retains existing source bounds. `commit()` settles the last curve piece; `cancel()` restores the original snapshot. Budget errors leave the previous published snapshot and accepted sample state intact. The caller checks project editability/visibility and supplies the remaining image/mask pixel budget from other layers.

`materializeLayer()` assembles the exact final layer in the current origin-zero Raster representation. An aligned result shares unaffected source and changed tile handles. An unaligned crop copies tile rows into a new tile grid and therefore costs time and memory proportional to the resulting layer area. It never calls Raster::rgba/fromRgba to flatten the image. Attached masks expand with white outside the original extent; explicit mask placement and linkage stay fixed. Mask targets preserve the image and layer geometry. Flat GrayRaster still requires full mask allocation at final assembly. The transient mask `previewExterior` field is cleared from final layers.

`previewLayer(documentX,documentY,documentWidth,documentHeight,maxPixels=4194304)` creates a temporary layer for a viewport render. It inverse-maps the requested rectangle, adds two source pixels of interpolation halo and intersects the source bounds. The result uses exact source pixels when they fit the budget; larger requests increase a power-of-two sampling step. Lower-resolution previews use point sampling and can alias thin features. This is a display candidate, not a Mac area-filter match or an export representation. New logical raster storage is bounded by maxPixels, with tile-edge padding of at most one 256-pixel row/column. Existing shared original assets retain their separate lifetime.

Image preview crops preserve attached-mask alignment or explicit mask placement. Mask-only previews retain the original image and give the cropped mask a temporary placement. Folder/adjustment mask previews move the temporary layer's mask geometry because the canonical renderer applies those masks using the layer transform. A cropped placed mask keeps the complete current mask's exterior black/white value via rendering-only `Mask::previewExterior`; inferring that value from cropped edges is incorrect. The native regression intentionally uses a crop with black edges from a full mask with a white exterior. Current full-mask edge analysis uses the existing native thumbnail approximation and can inspect more than the viewport; it allocates no full gray image.

The host must keep its canonical document unchanged during pointer movement, replace the target layer only in a temporary viewport document, and pass the renderer's complete tile-expanded document footprint to previewLayer. A raw visible rectangle is insufficient when CompositeCache renders neighboring tile pixels. On mouse-up, materialize the full committed layer once and install one history entry. Cancel discards temporary previews. Never save, export, store in history, or use a viewport layer for a complete render. Root owns this host integration and stale-revision checks.
