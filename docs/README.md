# Documentation

These guides use the four [Diátaxis](https://diataxis.fr/) purposes. People and coding agents share the same pages; the source code remains the implementation reference.

| Purpose | Read this |
| --- | --- |
| Tutorial: learn by making something | [After the wind](../demo/README.md): import, remove a background, arrange layers, edit, save, and export |
| How-to: accomplish a task | [Use the editor](user-guide.md), [build from source](source-package.md), [install or build packages](packaging.md) |
| Reference: look up a contract or current behavior | [Shortcuts](user-guide.md#common-shortcuts), [project format](project-format-v7.md), [release notes](release-notes.md), [known issues](../KNOWN-ISSUES.md) |
| Explanation: understand the design | [Architecture and upstream relationship](architecture.md) |

For changes, start with [contributing](../CONTRIBUTING.md). [Validation](../VALIDATION.md) summarizes measured results and their limits. Historical plans and generated reports are not part of the documentation set.
